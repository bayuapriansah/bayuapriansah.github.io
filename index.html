01

Dasar Web

Tiga bahan pokok sebuah halaman web.

</> HTML

HTML adalah singkatan dari Hypertext Markup Language. HTML memungkinkan seorang user untuk membuat dan menyusun bagian paragraf, heading, link atau tautan, dan blockquote untuk halaman web dan aplikasi.

HTML bukanlah bahasa pemrograman, dan itu berarti HTML tidak punya kemampuan untuk membuat fungsionalitas yang dinamis.

{ } CSS

CSS adalah bahasa Cascading Style Sheet dan biasanya digunakan untuk mengatur tampilan elemen yang tertulis dalam bahasa markup, seperti HTML.

CSS berfungsi untuk memisahkan konten dari tampilan visualnya di situs.

$ jQuery

jQuery adalah JavaScript Library, kumpulan kode/fungsi JavaScript yang dulunya harus dibuat manual oleh user, tetapi sekarang cukup dipanggil dengan mudah seperti Fade In, Fade Out, Slide In, Slide Show, dll.

02

Bootstrap Container

Wadah untuk semua elemen grid di Bootstrap.

Container merupakan wadah yang digunakan pada framework Bootstrap untuk menampung semua elemen Grid System atau elemen lainnya dari framework Bootstrap. Ada dua jenis container: .container dengan lebar tetap di tiap breakpoint, dan .container-fluid yang selalu memenuhi lebar layar.

.container
<div class="container">
  <h1>Halaman pertama belajar Bootstrap</h1>
  <p>hallo. .
  ini adalah halaman pertamaku menggunakan bootstrap</p>
</div>
.container-fluid
<div class="container-fluid">
  <h1>Halaman pertama belajar Bootstrap</h1>
  <p>hallo. .
  ini adalah halaman pertamaku menggunakan bootstrap</p>
</div>
03

jQuery Effect

Menampilkan, menyembunyikan, dan menganimasikan elemen.

Dalam jQuery ada istilah Effect, yaitu sesuatu mengenai menampilkan dan menyembunyikan suatu elemen, menggerakkan elemen, dan menganimasikan elemen. Ada tiga jenis effect:

1 Effect Fade

Digunakan untuk menghilangkan atau menampilkan elemen secara perlahan, biasa digunakan untuk transisi sebuah objek dengan objek lain.

  • fadeIn()
  • fadeOut()
  • fadeTo()

2 Effect Slide

Digunakan untuk menghilangkan atau menampilkan elemen seperti membuka/menutup sesuatu.

  • slideUp()
  • slideDown()
  • slideToggle()

3 Effect Animate

Digunakan untuk menggerakkan atau menganimasikan suatu elemen dengan properti CSS yang kita tentukan sendiri.

  • animate()

index.php
<?php
$text_satu    = "SELAMAT DATANG PESERTA UJIAN KEPEGAWAIAN";
$text_dua     = "PERIKSA KARTU UJIAN ANDA DAN ALAT TULIS ANDA";
$jFont        = "arial";

$warna_kedua  = "green";

echo "<div style='text-align: $tAlign; font-family: $jFont;'>";
echo "<br>";
echo "<h2 style='color: $warna_kesatu'>$text_satu</h2>";
echo "<br>";
echo "<h3 style='color: $warna_kedua'>$text_dua</h3>";
echo "<br>";
echo "</div>";
?>
06

Grid System Bootstrap

Mengatur lebar komponen agar website responsif.

Grid System adalah sistem pengaturan lebar untuk masing-masing komponen yang ingin kita buat. Pengaturan ini bertujuan untuk mengatur ke-responsif-an website yang kita bangun. Beberapa class dasar Bootstrap untuk mengatur grid:

* .col-*

Mengatur grid secara otomatis untuk semua ukuran layar.

sm .col-sm-*

Untuk ukuran layar yang berukuran kecil (≥ 576 px).

md .col-md-*

Untuk ukuran layar yang berukuran sedang (≥ 720 px).

lg .col-lg-*

Untuk ukuran layar yang berukuran besar (≥ 992 px).
